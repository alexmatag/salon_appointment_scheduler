# Salon Appointment Scheduler ✂️

Interactive CLI program built with Bash and PostgreSQL to manage salon services, register new customers, and book appointments.

## Project Structure

* **`salon.sql`**: Complete database dump containing the relational schema (`customers`, `appointments`, `services` tables) and the initial catalog of salon services.
* **`salon.sh`**: Bash script that provides an interactive menu. It connects to the PostgreSQL database to validate user inputs, retrieve existing records, insert new customer data, and schedule appointments.

## Technologies Used

* PostgreSQL
* Bash Scripting
* SQL
